Why Tuckaway

Set it once

The mouse keeps five profiles in its own memory. Tuckaway writes them there, so your setup works on any computer, even one that has never seen Tuckaway.

Your words, your keyboard

Actions read like “Copy” and “DPI down”. Shortcuts follow your keyboard layout, so on AZERTY, Select all really is Ctrl+A.

See it before you save it

Lighting previews live on the mouse, and Apply lists every change in plain words before anything is written.

Careful with your mouse

  • Backup first. A full backup is saved before every write.
  • Checked twice. Every sector is read back and compared byte for byte.
  • Only what you changed. Unknown bytes are kept as they were.
  • Factory profiles untouched. The ROM is never written, so Factory reset always works.
  • No stale writes. If the mouse changed since it was loaded, nothing is written.
  • Undo anytime. Restore any backup from the settings menu.

Questions

Which mice does it support?

The wired Logitech G502 HERO (USB id 046d:c08b). Other mice that use the same onboard format may follow; dumps from other models are welcome on GitHub.

Do I need G HUB?

No. Tuckaway talks to the mouse directly. Close G HUB while you use Tuckaway, or uninstall it.

Windows says it protected my PC.

The exe isn't code-signed yet. Choose More info, then Run anyway, or compare the file with SHA256SUMS.txt on the release page first.

The lighting doesn't change on my mouse.

Windows Dynamic Lighting can take over the LEDs. Turn it off for the mouse in Windows Settings; the Lighting tab tells you when it's in the way.
